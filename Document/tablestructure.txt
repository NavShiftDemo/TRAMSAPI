================================================================================
TRAMSAPI - DATABASE TABLE & COLUMN STRUCTURE

Prefix: tb_trams_
Case Convention: Lowercase Snake Case (table names & column names)

--------------------------------------------------------------------------------
1. tb_trams_tenant_master (TenantMaster)
--------------------------------------------------------------------------------
Description: Stores registered company / business tenants.
Columns:
  * tenant_id            : BIGINT, PRIMARY KEY, AUTO INCREMENT
  * business_name        : VARCHAR(150), NOT NULL
  * tenant_code          : VARCHAR(50), NOT NULL, UNIQUE
  * company_email        : VARCHAR(150), NULL
  * company_phone_no     : VARCHAR(20), NULL
  * is_active            : BOOLEAN, NOT NULL, DEFAULT true
  * created_at           : TIMESTAMP WITH TIME ZONE, NOT NULL
  * created_by           : BIGINT, NULL
  * updated_at           : TIMESTAMP WITH TIME ZONE, NULL
  * updated_by           : BIGINT, NULL

--------------------------------------------------------------------------------

  * tenant_id            : BIGINT, NOT NULL, FK -> tb_trams_tenant_master(tenant_id)
  * name                 : VARCHAR(150), NOT NULL
  * email                : VARCHAR(150), NULL
  * phone_no             : VARCHAR(20), NOT NULL
  * alternate_phone_no   : VARCHAR(20), NULL
  * address              : VARCHAR(255), NULL

  * created_at           : TIMESTAMP WITH TIME ZONE, NOT NULL
  * created_by           : BIGINT, NULL
