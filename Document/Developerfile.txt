================================================================================
TRAMSAPI - DEVELOPER GUIDE & COMMAND REFERENCE
================================================================================

1. PROJECT INITIALIZATION & ARCHITECTURE SETUP
--------------------------------------------------------------------------------
Architecture Pattern: Clean Architecture (.NET 10.0 Web API)

# Create Solution
dotnet new sln -n TRAMSAPI

# Create Projects
dotnet new webapi -n TRAMSAPI.Web -f net10.0
dotnet new classlib -n TRAMSAPI.Application -f net10.0
dotnet new classlib -n TRAMSAPI.Domain -f net10.0
dotnet new classlib -n TRAMSAPI.Infrastructure -f net10.0

# Add Projects to Solution
dotnet sln add TRAMSAPI.Web/TRAMSAPI.Web.csproj
dotnet sln add TRAMSAPI.Application/TRAMSAPI.Application.csproj
dotnet sln add TRAMSAPI.Domain/TRAMSAPI.Domain.csproj
dotnet sln add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj

# Add Inter-Project References
dotnet add TRAMSAPI.Application/TRAMSAPI.Application.csproj reference TRAMSAPI.Domain/TRAMSAPI.Domain.csproj
dotnet add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj reference TRAMSAPI.Domain/TRAMSAPI.Domain.csproj
dotnet add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj reference TRAMSAPI.Application/TRAMSAPI.Application.csproj
dotnet add TRAMSAPI.Web/TRAMSAPI.Web.csproj reference TRAMSAPI.Application/TRAMSAPI.Application.csproj
dotnet add TRAMSAPI.Web/TRAMSAPI.Web.csproj reference TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj


2. NUGET PACKAGES INSTALLATION
--------------------------------------------------------------------------------
# Infrastructure Layer (Entity Framework Core & PostgreSQL Provider & BCrypt)
dotnet add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj package Npgsql.EntityFrameworkCore.PostgreSQL --version 10.0.0
dotnet add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj package Microsoft.EntityFrameworkCore.Design --version 10.0.0
dotnet add TRAMSAPI.Infrastructure/TRAMSAPI.Infrastructure.csproj package BCrypt.Net-Next --version 4.2.0

# Application Layer (Password Hashing / Security)
dotnet add TRAMSAPI.Application/TRAMSAPI.Application.csproj package BCrypt.Net-Next --version 4.2.0

# Web Layer (EF Core Design for Migrations, Swagger/OpenAPI)
dotnet add TRAMSAPI.Web/TRAMSAPI.Web.csproj package Microsoft.EntityFrameworkCore.Design --version 10.0.0
dotnet add TRAMSAPI.Web/TRAMSAPI.Web.csproj package Swashbuckle.AspNetCore --version 6.4.0
dotnet add TRAMSAPI.Web/TRAMSAPI.Web.csproj package Microsoft.AspNetCore.OpenApi --version 8.0.1

5. INFRASTRUCTURE & PERSISTENCE CONFIGURATION
--------------------------------------------------------------------------------
- Database Context:
  TRAMSAPI.Infrastructure/Persistence/ApplicationDbContext.cs
  Contains DbSets for all 32 Domain entities.

- Entity Configurations:
  Located in: TRAMSAPI.Infrastructure/Persistence/Configurations/
  Each entity has a dedicated IEntityTypeConfiguration<T> class:
  * Table names prefix: "tb_trams_<entity_name>"
  * Table and column names formatted in lowercase snake_case
  * All Enums converted and saved in DB as integers: .HasConversion<int>()

- Seed Data:
  Located in: TRAMSAPI.Infrastructure/Persistence/Seeds/
  1. TableListSeedData.cs: Seeds all 32 table names into tb_trams_table_list.
  2. UserSeedData.cs: Seeds Default Tenant, Developer Role, Admin User (password hashed with BCrypt.Net-Next), and UserRoleMapping.

- Dependency Injection:
  TRAMSAPI.Infrastructure/DependencyInjection.cs:
  services.AddInfrastructureServices(configuration);
  Called in TRAMSAPI.Web/Program.cs.


6. ENTITY FRAMEWORK CORE MIGRATION COMMANDS
--------------------------------------------------------------------------------
# Build Solution
dotnet build

# Add Migration (run from solution root E:\TRAMS\TRAMSAPI)
dotnet ef migrations add <MigrationName> --project TRAMSAPI.Infrastructure --startup-project TRAMSAPI.Web --output-dir Persistence/Migrations

# Update / Apply Migration to Database
dotnet ef database update --project TRAMSAPI.Infrastructure --startup-project TRAMSAPI.Web

# Remove Last Migration (if needed before pushing)
dotnet ef migrations remove --project TRAMSAPI.Infrastructure --startup-project TRAMSAPI.Web

# Generate SQL Script for Production / Review
dotnet ef migrations script --project TRAMSAPI.Infrastructure --startup-project TRAMSAPI.Web -o migration.sql --idempotent
